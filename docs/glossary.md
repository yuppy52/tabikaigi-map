## グループとメンバー

| 用語 | 意味 |
|---|---|
| グループ | 友達同士で地図を共有する単位。招待URLごとに1つ作られ、最大20人まで参加できる |
| 招待URL | グループに参加・閲覧するためのURL。知っている人は誰でも参加・閲覧できる。再発行はしない |
| メンバー | グループに参加している人。ログインなしなら名前だけの存在、ログインありならアカウントと紐づく |
| 作成者 | グループを作った人。グループの管理できる人の初期設定（「誰でも」）を持ち、「作成者のみ」に変えられる |
| 管理できる人 | メンバーの退出・削除・名前の変更、グループ名の変更・削除ができる人の範囲。「誰でも」（初期値）か「作成者のみ」を作成者が選ぶ |
| 名前 | メンバーの表示名。1グループの中で重複しない |
| 信頼ベース | 本人確認をせず、名前を入力すれば誰でもその人として操作できる仕組み。ログインなしの前提になっている考え方 |

## 地図と「行った」

| 用語 | 意味 |
|---|---|
| 行った | メンバーやアカウントが訪れたことのある都道府県。地図の色や一覧の状態で表す |
| わたし | 地図の表示モードの1つ。自分の「行った」を付け外しする |
| みんな | 地図の表示モードの1つ。行った人が多い県ほど濃く塗り、全員まだ行っていない県を強調する |
| メンバー別 | 地図の表示モードの1つ。選んだメンバー1人の「行った」だけを表示する |

## アカウントとログイン

| 用語 | 意味 |
|---|---|
| ログインなし | 会員登録せず、名前を入れるだけで参加する使い方。裏では匿名で認証しているが、利用者には見せない。「行った」はグループのメンバーごとに持つ |
| ログインあり | メール＋パスワードまたはGoogleでログインする使い方。「行った」はアカウントに保存し、参加している全グループに同期する |
| 匿名（匿名認証） | ログインなしで使うときに、裏側で自動的に行われる認証。利用者に見せる概念ではない。これだけでは「アカウント」とは呼ばない |
| 認証済み | 匿名を含め、何らかの形でサインインしている状態。Firestoreのセキュリティルールで「書き込んでよいか」の条件に使う |
| ログイン済み | メールまたはGoogleでサインインしている状態（匿名を含まない）。例：「管理できる人」を「作成者のみ」に変えられるのは、ログイン済みの作成者だけ |
| アカウント | メールアドレスやGoogleと結びついた、ログイン済みの人の記録（`users/{uid}`）。匿名の認証だけの状態は含まない |
| 昇格 | ログインなしで参加していた人が、**まだどのアカウントにも使われていない**メールやGoogleでログインしたとき、匿名のときと同じ `uid` のままアカウントにすること。作成者の立場もそのまま引き継ぐ。すでに別のアカウントで使われているメールやGoogleでログインする場合は昇格にならず、「合算」の流れになる（このとき `uid` は変わり、作成者の立場は引き継がない）。同じ端末で参加している他のグループのメンバーとの紐づけがどうなるかは要確認 |
| 合算 | グループでの「行った」（G）とアカウントの「行った」（U）が両方ある状態で、確認の上でこれらを1つにまとめること |
| 紐づけ | 名前だけで参加していたメンバーに、ログインしたアカウントを結びつけること。以後はそのメンバーを本人しか編集できなくなる |
| 本人確認 | ログインした人がグループに入るとき、同じ名前の（アカウントと紐づいていない）メンバーが自分かどうかを確認するダイアログ |

## 画面

| 用語 | 意味 |
|---|---|
| グループ設定 | グループ名、管理できる人、メンバーの削除、グループの削除を行う画面 |
| マイページ | ログインしたときだけ入れる、アカウントの「行った」や表示名を見る画面 |
| グループ一覧 | ログインしたときだけ入れる、参加中のグループを切り替える画面 |

## その他

| 用語 | 意味 |
|---|---|
| 端末 | 利用者が使っているスマホやPC。ログインなしのとき、前回この端末で使った名前を覚えておくのに使う |
