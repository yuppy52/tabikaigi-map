## グループとメンバー

| 用語 | 意味 |
|---|---|
| グループ | 友達同士で地図を共有する単位。招待URLごとに1つ作られ、最大20人まで参加できる。メンバーが0人になると削除される |
| 招待URL | グループに参加・閲覧するためのURL。知っている人は誰でも参加・閲覧できる。再発行はしない |
| メンバー | グループに参加している人。ログインなしなら名前だけの存在、ログインありならアカウントと紐づく |
| 作成者 | グループを作った人（作成者のメンバー）。名前で決まり、アカウントの `uid` では決まらない。グループの管理できる人の初期設定（「誰でも」）を持ち、「作成者のみ」に変えられる |
| 管理できる人 | メンバーの削除、グループ名の変更、グループの削除ができる人の範囲。「誰でも」（初期値）か「作成者のみ」を作成者が選ぶ。退出（自分のメンバーを消す）と、自分の名前の変更は、この設定に関係しない |
| 名前 | メンバーの名前。グループごとに入力する（ログインありも同じ。アカウントは表示名を持たない）。1グループの中で、ログインあり・なしを問わず重複しない。変えられるのはログインありの本人だけ。ログインしたメンバー（紐づけ済み）の名前では、ほかの人は参加できない |
| 退出 | メンバーが自分でグループから抜けること。グループでの「行った」は消える（アカウントの「行った」は残る）。最後の1人が退出すると、グループも削除される |
| 信頼ベース | 本人確認をせず、名前を入力すれば誰でもその人として操作できる仕組み。ログインなしの前提になっている考え方 |

## 地図と「行った」

| 用語 | 意味 |
|---|---|
| 行った | メンバーやアカウントが訪れたことのある都道府県。地図の色や一覧の状態で表す |
| わたし | 地図の表示モードの1つ。自分の「行った」を付け外しする |
| みんな | 地図の表示モードの1つ。行った人が多い県ほど濃く塗り、全員まだ行っていない県を強調する |
| メンバー別 | 地図の表示モードの1つ。選んだメンバー1人の「行った」だけを表示する |

## アカウントとログイン

| 用語 | 意味 |
|---|---|
| ログインなし | 会員登録せず、名前を入れるだけで参加する使い方。裏では匿名で認証しているが、利用者には見せない。「行った」はグループのメンバーごとに持つ |
| ログインあり | メール＋パスワードまたはGoogleでログインする使い方。「行った」はアカウントに保存し、参加している全グループに同期する |
| 匿名（匿名認証） | ログインなしで使うときに、裏側で自動的に行われる認証。利用者に見せる概念ではない。これだけでは「アカウント」とは呼ばない |
| 認証済み | 匿名を含め、何らかの形でサインインしている状態。Firestoreのセキュリティルールで「書き込んでよいか」の条件に使う |
| ログイン済み | メールまたはGoogleでサインインしている状態（匿名を含まない）。例：「管理できる人」を「作成者のみ」に変えられるのは、ログイン済みの作成者だけ |
| アカウント | メールアドレスやGoogleと結びついた、ログイン済みの人の記録（`users/{uid}`）。匿名の認証だけの状態は含まない。表示名は持たない |
| 昇格 | ログインなしで参加していた人が、**まだどのアカウントにも使われていない**メールやGoogleでアカウントを作ったとき、匿名のときと同じ `uid` のままアカウントにすること。すでに別のアカウントで使われているメールやGoogleでログインする場合は昇格にならず、「合算」の流れになる（このとき `uid` は変わる）。どちらの場合も、作成者のメンバーを紐づければ作成者の立場を引き継ぐ。同じ端末からログインなしで参加している他のグループのメンバーは、自動では紐づけない（暫定） |
| 合算 | グループでの「行った」（G）とアカウントの「行った」（U）が両方ある状態で、確認の上でこれらを1つにまとめること |
| 紐づけ | 名前だけで参加していたメンバーに、ログインしたアカウントを結びつけること。以後はそのメンバーを本人しか編集できなくなる |
| 本人確認 | ログインした人がグループに入るとき、入れた名前と同じ名前の（アカウントと紐づいていない）メンバーが自分かどうかを確認するダイアログ。自己申告で、本当に本人かは確かめていない |
| ログアウト | ログインありの状態をやめること。トップの画面に戻り、以後はログインなしとして扱う |
| 退会 | ログインありの人が、アカウントを削除すること。参加していた各グループのその人のメンバーも消える（退出と同じ扱い） |

## 画面

| 用語 | 意味 |
|---|---|
| トップ | アプリの入口の画面。ログアウトした後もここを開く。中身は基本設計で決める（open-questions の Q-016） |
| グループ設定 | グループ名、管理できる人、メンバーの削除、グループの削除、退出、自分の名前の変更（ログインありのみ）を行う画面 |
| マイページ | ログインしたときだけ入れる、アカウントの「行った」とメールアドレスを見て、ログアウト・退会する画面 |
| グループ一覧 | ログインしたときだけ入れる、参加中のグループを切り替える画面 |
