## 画面遷移図

```mermaid
flowchart TD
  Start(["URL を開く"]) --> IsLine{"LINE の<br/>アプリ内ブラウザ?"}
  IsLine -- "はい（ログイン時など）" --> ExtGuide["外部ブラウザの案内"]
  IsLine -- "いいえ" --> Route{"URL"}

  Route -- "/" --> Top["トップ"]
  Route -- "/g/{groupId}" --> Exists{"グループがある?"}
  Exists -- "ない" --> Err["エラー"]
  Exists -- "ある" --> Known{"自分の uid のメンバーがいる、<br/>または端末の枠と名前が合う?"}
  Known -- "はい" --> Group
  Known -- "いいえ（覚えていた名前が合わなければ<br/>「前回の名前が見つかりませんでした」）" --> Join["参加"]
  Join -- "満員" --> Err
  Join --> Group

  Top --> Create["グループ作成"] --> Invite["招待"] --> Group
  Top --> Login["ログイン"]

  Group["グループ<br/>わたし／みんな／メンバー別"] --> Pref["県の詳細"]
  Group --> Invite
  Group --> Settings["グループ設定"]
  Group --> Login

  Login --> Merge{"データの<br/>扱い"}
  Merge -- "確認が要る" --> MergeDlg["合算の確認"] --> AfterLogin
  Merge -- "確認は不要" --> AfterLogin{"どこから来た?"}
  AfterLogin -- "グループから" --> Group
  AfterLogin -- "トップから" --> List["グループ一覧"]

  List --> Group
  List --> Create
  List --> My["マイページ"]
  My -- "ログアウト・退会" --> Top
  Group -. "ログイン時・同じ名前がいる" .-> SameName["本人確認"] --> Group
```

## 画面のルール

- スマホ幅を基本にする（モックと同じ）
- 招待URLを LINE で開いても、`?openExternalBrowser=1` で外部ブラウザに移る
- ログインしていないときは、グループ一覧とマイページには入れない
