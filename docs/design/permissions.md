## この文書について

- 2026-11-06 の時点で、この表はログインのない形。コードとテスト（`api/`・`web/`）は、ロードマップの L-2（API）・L-3（画面）で合わせるまで、ログインの入口が残っている
- 「誰が・何を・できるか」と「それをどこで守るか」を、操作ごとに並べる。決まりの正本は requirements の各要件で、ここはその一覧
- 「守る場所」の書き方：
  - **API**：Hono の API が、書き込む SQL の `WHERE`（条件付きの `UPDATE` を含む）で確かめる（形は [data-model.md](data-model.md) の「設計のポイント」）
  - **制約**：D1 の `UNIQUE`・`CHECK`・外部キー・トリガー
  - **画面**：画面だけの決まり。改造した画面なら破れる（破れても増える被害がないものだけ。下の「画面だけで止めているもの」）
- 記号：
  - ○ できる
  - × できない。**API か制約で断る**（テストは `api/test/` にある。ローカルで済んだ。本物の D1 での確かめは Phase 2）
  - ×画 できない。ただし**画面だけで止めている**（API は通す。テストしない）
  - — その立場では起きない
- 〔未〕は、本物の D1 で動くかをまだ確かめていない守り方（トリガー。Phase 2 の最初のデプロイで試し、使えなければ API とテストで守る）

## 人の区別

言葉は [用語集](../glossary.md) にそろえる。

| 立場 | どういう人か |
|---|---|
| 来訪者 | まだそのグループに入っていない人。招待URL（グループID）を知っている |
| メンバー | 名前で入っている人。端末がメンバーの番号を覚えている（[auth-flow](auth-flow.md) の「端末が覚えるもの」） |

端末が覚えているかで、画面の入口が分かれる（API から見た立場は変わらない）。

| 端末 | 開いたときの画面 |
|---|---|
| 覚えていて、そのメンバーが今もいる | 参加の画面を出さず、そのメンバーとしてグループを開く（REQ-024）。共用の端末では、前に使った人として開く（「メンバーを変更する」で忘れてもらう：requirements の「分かっている限界」） |
| 覚えていたが、そのメンバーがいない | 忘れて、「前回の名前が見つかりませんでした」と参加の画面（REQ-025） |
| 覚えていない（初めて、別のブラウザ、Safari で消えた） | 参加の画面 |

### API から見える区別

API が確かめられるのは次のものだけ。

1. グループID（URL に入っている）
2. 送られてきたメンバーの番号（そのグループのメンバーか）

ログインがないので、API では「メンバー」と「来訪者」を見分けられない。そのため、メンバーに許す操作は、API の上では「グループIDを知っている人なら誰でも」できる。招待URLを知っていれば参加して同じことができるので、増える被害はない（requirements の「分かっている限界」）。

## グループの外の操作

| 操作 | 誰でも | 守る場所 | 要件 |
|---|---|---|---|
| グループを作る | ○（最初のメンバーになる） | API（Turnstile。Q-031） | REQ-001 |
| ほかの人のグループを探す・一覧する | × | 推測できないグループID、一覧する API を作らない | NFR-005・NFR-006 (7) |

2026-11-06 に、「管理できる人」（誰でも／作成者のみ）の設定をなくした。管理の操作（削除・グループ名の変更）は、いつもメンバーなら誰でもできる。

## 運営者

運営者は、`wrangler` で D1 を直接読み書きできる（アプリの権限の外）。使うのはバックアップ（NFR-017）、削除の依頼への対応（NFR-018）、集計（NFR-010）のときだけにする。

## 画面だけで止めているもの

表の「×画」の欄。改造した画面なら破れる。

| 画面だけの決まり | 改造した画面でできること | 受け入れる理由 |
|---|---|---|
| 参加する前は地図を見せない（REQ-002） | 参加しないで地図を読める | 招待URLを知っていれば参加して見られる |
| 参加する前はリアルタイムにつながない | 参加しないで知らせを受けられる | 同上 |
| 「行った」の付け外しと退出は、その名前で入った人がする（REQ-022・REQ-023） | 参加しないで、付け外し・退出させられる | 信頼ベースで、同じ名前を入れれば誰でもできる |
| 管理の操作はメンバーがする | 参加しないで削除・名前の変更ができる | 招待URLを知っていれば参加して同じことができる |

どれも requirements の「分かっている限界」（招待URLを知っている人は、参加しなくても、メンバーにできることはすべてできる）に書いてある。
