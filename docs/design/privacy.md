# プライバシーポリシーに書くこと

状態：下書き（2026-10-16：運営者の氏名・住所の出し方をユーザーと決めた。2026-10-12：`/review-docs`（24件）を受けて、問い合わせの情報と保存期間、返事に使うメール、Sentry に IP が届くこと、保存期間の例外（確認待ちのアカウント、端末の記憶、`sessionStorage`）を足した。2026-10-12：Q-028 を推奨案で決めて作った。文面は Phase 2 でページを作るときに書く）

プライバシーポリシー（`/privacy`、NFR-008）に何を書くかのチェックリスト。法律上どこまで必要かを 2026-10-12 に `researcher` で調べた結果をもとにした。法律の助言ではなく、設計の判断の材料。

## 前提（仮定を含む）

- 運営者は日本に住む個人1人で、収入はない（MVP では広告なし：Q-029）。法人や屋号はない（仮定）
- 扱う情報は NFR-007 のとおり。メールアドレスはアプリのデータベース（D1）には持たず、Firebase Authentication（Google）が持つ
- 外部に送る先は、Cloudflare（ホスティング、データベース）、Google（Firebase Authentication）、Sentry（エラーの把握。グループID・名前・メールアドレスは送らず、通信で届く IP は保存しない設定にする：[architecture](architecture.md) の「エラーの送り方」）。アクセス解析は使わない（Q-025）
- 利用者は最大で数百人（NFR-015）

## 法律の調べた結果

| 法律 | 結論 | 確かさ |
|---|---|---|
| 個人情報保護法：運営者は「個人情報取扱事業者」か | 「事業」は営利・非営利を問わず、サークルも当たりうる（PPC の Q&A Q1-54）。件数での除外もない（Q1-50）。個人の趣味が外れると言い切れないので、**当たる前提で書く** | 公式。趣味の個人を直接扱った資料はない（要確認） |
| 同：公表すること（第21条・第32条） | 利用目的、運営者の氏名と住所、開示などの請求の手続、安全管理措置、苦情の申出先。第32条は「本人の求めに応じて遅滞なく回答する場合を含む」ので、Web に載せず、聞かれたら答える形も条文上はある（Q9-1・Q9-3 は手続と安全管理措置についてこれを認めている） | 公式。個人の氏名・住所をこの形にしてよいと明言した資料はない（要確認） |
| 同：外国のクラウド（第28条、外的環境の把握） | クラウドの事業者が個人データを取り扱わない契約なら「提供」に当たらない（Q7-53・Q12-3）。それでも、安全管理措置として、事業者の国とサーバーの国を示す。サーバーの国を特定できなければ、その旨と理由を書く（Q10-25） | 公式。Cloudflare・Google・Sentry の契約がそうなっているかは要確認 |
| 電気通信事業法の外部送信規律（第27条の12） | 電気通信事業を「営む」者だけが対象（総務省 FAQ Q1-8）。「営む」には利益を得ようとすることが要るという解説が多く、無料・広告なしの MVP は対象外の見込み。広告を入れたら対象になる前提で見直す | 公式（FAQ）とブログ。対象かどうかは要確認 |
| クッキー・localStorage の同意 | 同意のバナーを一般に義務づける法律は見つからなかった。`localStorage` にアプリのためだけに覚えるもの（自分のサーバーにしか送らない）は外部送信に当たらず、同意は要らない見込み | 公式（総務省 FAQ Q1-5・Q1-6）と見立て。要確認 |
| 利用規約・特定商取引法の表示 | 利用規約は法律の義務ではない。特定商取引法は有償の取引が対象で、無料のアプリは対象外 | 公式（消費者庁）と見立て |
| 2026年の個人情報保護法の改正 | 2026-07-17 に公布、公布から2年以内に施行。16歳未満の個人情報の扱いなどが入る見込み。友達のグループに16歳未満が入ることはありうるので、施行の前に見直す | 公式（成立・公布）。中身はブログ（要確認） |

## 書く項目

2026-10-12 に決めた（ユーザーが「7. の残りを一気に進めて」と頼んだので、推奨案で決めた）。運営者の氏名・住所の出し方は、2026-10-16 にユーザーと決め直し、推奨案のままにした。

| 項目 | 中身 | 必須か |
|---|---|---|
| 運営者 | ハンドルネームと、問い合わせのフォーム（NFR-018）。氏名と住所は「請求があれば遅滞なく回答する」と書く（2026-10-16 にユーザーと決めた。法律の「本人の知り得る状態」には「求めに応じて遅滞なく回答する場合」も含まれる。ただし氏名・住所にこの形を使ってよいと明言した公式の資料はないので、公開の前に個人情報保護法相談ダイヤル（03-6457-9849、平日 9:30〜17:30：https://www.ppc.go.jp/personalinfo/pipldial/ ）で、この形でよいかを確かめる：要確認。選ばなかった案：氏名と住所を載せる（自宅の住所が誰でも見られる）、バーチャルオフィスの住所を載せる（月に数百〜千円ほど）） | 必須（第32条） |
| 取得する情報 | メンバーの名前、行った都道府県、メールアドレス（ログインする人。Google でログインしたときの表示名や写真の URL も Google から渡る）、グループごとの最後に開かれた日、問い合わせの返信先のメールアドレスと本文（ログインなしの人も入れる）。ホスティングが自動で残す記録（IP アドレス、おおよその場所、URL）は、自分で書くログには残さないこと | 念のため |
| 利用目的 | アプリを使ってもらうため（地図の共有、本人の確認、ログイン）、不具合の対応、問い合わせへの返事（このアプリ用のメールアドレスから送る）、利用状況を数えること（人数や回数だけ。一人ひとりの行動は追わない：NFR-010） | 必須（第21条・第32条） |
| 端末（ブラウザ）に覚えるもの | グループごとのメンバーの番号と名前、ログインの状態の目印（`localStorage`）、ログインした後に戻るグループ（`sessionStorage`。タブを閉じると消える）。目的と、消し方（ブラウザのサイトデータを消す）。端末の記憶はログアウト・退会しても残る（requirements の「分かっている限界」）。クッキーは使わない（Firebase のログインの状態はブラウザの保存場所に残る） | 念のため（NFR-008） |
| 外部のサービスと送る情報 | Cloudflare（画面の配信、データの保存、ボット対策）、Google（ログイン、確認メール）、Sentry（エラーの内容。グループID、名前、メールアドレスは送らない。通信で届く IP は保存しない設定）。問い合わせへの返事に使うメールのサービス（Gmail などを使うなら Google）。それぞれの目的 | 念のため（外部送信規律の対象になったら必須） |
| 保存する期間 | 自動では消さない。退出・削除・退会で消える。ただし、データベースの復元用に7日、運営者の手元のバックアップに次の版を出すまで、ホスティングのログ（自分で書いたもの）に3日（2026-12-01 から7日）、Sentry に Sentry の保存期間（要確認）残る（NFR-008・NFR-017）。問い合わせの返信先と本文は、対応が済んでから3か月で消す。メールアドレスの確認が済んでいないアカウントは、Firebase に残り、運営者も消さない（requirements の「分かっている限界」） | 念のため |
| 消し方・頼み方 | 自分で消す方法（退出、退会、メンバーの削除）と、問い合わせのフォームから頼む方法。1か月以内に応じる（NFR-018） | 必須（開示などの請求の手続：第32条） |
| 安全管理措置 | 概要だけ：グループIDを推測できない文字列にする、書き込みの権限を保存先で守る、通信の暗号化、集計やバックアップは運営者の PC からだけ行う、バックアップを1つだけ残す。詳しいことは聞かれたら答える（Q9-3） | 必須（第32条・施行令第10条） |
| 外的環境の把握 | Cloudflare（米国）、Google（米国）、Sentry（米国。データの置き場所は組織を作るときに米国か EU を選ぶ：要確認）。データの保存場所は、Cloudflare の D1 はアジアの地域を指定するが、国は固定できないことと、その理由。サービスの国の個人情報の制度は、個人情報保護委員会の資料を参照すると書く | 必須（Q10-25） |
| 苦情の申出先 | 問い合わせのフォーム | 必須（施行令第10条） |
| 改定 | 改定の日付と、変えたときはこのページで知らせること | 念のため |

書かないもの：認定個人情報保護団体（入っていない）、クッキーの同意のバナー（使わない）、利用規約と特定商取引法の表示（MVP では作らない。要るようになったら、そのときに足す）。
