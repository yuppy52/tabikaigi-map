# ADR 0001：バックエンドに Firebase を使う

- 状態：**提案中**（レビューで確定する。2026-10-02：費用の心配から、基本設計で見直す。下の「見直しの理由」と [open-questions の Q-023](../open-questions.md)。2026-10-04：[ADR 0003](0003-backend-selection.md) で、Cloudflare Workers＋D1 に認証だけ Firebase Authentication を組み合わせる案 C を推奨にした。C に決まれば、この ADR は ADR 0003 で置き換える）
- 日付：2026-09-27

## 見直しの理由（2026-10-02）

従量課金で、個人開発では見積もれない金額の請求が来るのが怖い。Spark プランのままなら請求は発生しないはず（2026-10-03 に公式で確認：[ADR 0003](0003-backend-selection.md)）だが、課金が必要な機能（Cloud Functions など）を入れると Blaze プランになり、上限のない請求になりうる。基本設計で、費用に上限があるかを観点に加えて選択肢を比べ直し、決めたら新しい ADR を書く（この ADR は確定させずに、新しい ADR で置き換えるか確定するかを決める）。

あわせて、下の「決定」の「Spark プランで今の要件がすべて満たせる」は、運用の非機能要件（[requirements](../requirements.md) の NFR-010〜NFR-018：利用状況の集計、使用量の知らせ、エラーの把握、バックアップ、想定規模など）を足す前の判断なので、見直すときに確かめ直す（2026-10-03）。

## 背景

モックはデータをブラウザの `localStorage` に保存しているため、友達とデータを共有できない。保存先と認証の仕組みが必要。

条件：
- ログインなしでも使え、あとからメール＋パスワードや Google でログインできる
- ログインなしの人をあとからアカウントに移せる
- 趣味の規模なので、無料枠で運用したい
- 1人で開発・運用できる手軽さ

## 選択肢

| | Firebase（Auth + Firestore + Hosting） | Supabase（Auth + Postgres） | Cloudflare（Pages + Workers + D1） |
|---|---|---|---|
| 匿名 → ログインへの移行 | 標準機能（`linkWithCredential`） | 匿名ログインあり。アカウントへの移行も可能 | 自前で作る（または認証だけ Firebase と組み合わせる：ADR 0003 の案 C） |
| Google ログイン | 標準 | 標準 | 自前か外部サービス（同上） |
| アクセス制御 | セキュリティルール | RLS（SQL で書く） | API のコードで書く |
| サーバーのコード | 不要 | 不要 | 必要（Workers） |
| データの形 | ドキュメント（NoSQL） | リレーショナル | リレーショナル（SQLite） |
| 無料枠 | 余裕あり。使われないと止まる、という公式の記載は見つからない（2026-10-03 調査。要確認：Q-014） | 余裕あり。**しばらく使われないとプロジェクトが一時停止される**（※要確認） | 余裕あり |
| ローカルでのテスト | エミュレータ（JDK 21 が必要） | Docker で一式 | wrangler |

## 決定

**Firebase を使う。**

- 匿名認証からの昇格、Google ログインが標準で揃っていて、要件に一番素直に合う
- サーバーのコードを持たずに済み、セキュリティルールとそのテストだけ書けばよい
- 無料の Spark プランで今の要件がすべて満たせる（[architecture.md](../design/architecture.md)）
- Supabase は、友達グループのようにたまにしか使われない用途だと、無料枠の一時停止が響く（※Supabase と Cloudflare の欄は調査していない。確定前に調べる。2026-10-03 に [ADR 0003](0003-backend-selection.md) で調べた。Supabase の7日の一時停止は公式で確認）

## 影響

- データはドキュメント型なので、集計やリレーションが必要な機能（例：全グループ横断の統計）は作りにくい
- ルールで件数を数えられないなどの制約を、データの形で補う必要がある（メンバーの20枠など、[data-model.md](../design/data-model.md)）
- Cloud Functions が必要な機能（グループごとの OGP など）を足すと、有料の Blaze プランになる
- Google のサービスに依存する
