# 要件定義

状態：レビュー待ち

## 目的

友達グループで「今まで行ったことのある都道府県」を日本地図に塗って共有し、全員まだ行っていない県を見つけて、次の旅行先を決めやすくする。

## 利用者

- 友達同士の小さなグループ（1グループ最大20人）
- スマホで使う。招待URLは主に LINE で送られる

## 機能要件

### グループ
- グループを作ると招待URLが発行される。URLを知っている人は誰でも参加・閲覧できる
- 招待URLの再発行はしない（MVP）
- 1グループの上限は20人

### 地図
- **わたし**：地図か一覧をタップして、自分の「行った」を付け外しする
- **みんな**：行った人が多い県ほど濃く塗る。県をタップすると誰が行ったか見られる
- **全員まだ行っていない県**を強調表示する
- **メンバー別**：選んだ人の行った県だけを表示する
- メンバーの色は重複してよい

### ログインなしで使う
- 会員登録なし。名前を入れるだけで参加できる
- **名前がそのまま本人**になる。同じ名前を入れれば、誰でもその人として操作・編集できる（信頼ベース）
- 1つのグループの中で名前は重複させない
- 端末に前回の名前が残っていればそれを使う。残っていなくてもよい
- グループの切り替えはない。別のグループには別の招待URLから入る

### ログインして使う
- ログインの方法：メールアドレス＋パスワード、Google
- 参加しているグループを切り替えられる
- 「行った」はアカウントに保存され、参加している全グループに同期する。新しいグループに入っても入力し直さなくてよい
- ログインしたメンバーの「行った」と名前は、**本人しか編集できない**（信頼ベースの例外）

| | ログインなし | ログインあり |
|---|---|---|
| 入り方 | グループごとの招待URL | 招待URL、またはグループ一覧 |
| グループの切り替え | なし | あり |
| 「行った」 | グループのメンバーごとに持つ | アカウントに保存し、全グループに同期する |
| 編集できる人 | そのグループの誰でも | 本人だけ |

### ログインなしで参加していた人がログインしたとき

グループでの「行った」（G）とアカウントの「行った」（U）を次のように扱う。

| 状況 | 挙動 |
|---|---|
| U が空（はじめてのログイン） | 確認なしで G をアカウントに引き継ぐ |
| G が U にすべて含まれている | 確認なしで U を表示する |
| それ以外 | 確認を出す |

> アカウントに保存されている「行った」（N県）をこのグループに反映しますか？
> - **アカウントのデータを使う**：このグループでの入力は破棄する
> - **合算する**：G と U を合わせてアカウントに保存する（参加中の他のグループにも反映される）

### ログインした人がグループに入るとき
- 同じ名前のメンバーがいれば「この人はあなたですか？」と聞く
  - **はい**：そのメンバーをアカウントに紐づける。データは上の表と同じ流れで扱う
  - **いいえ**：別の名前を入力してもらう
- 同じ名前がいなければ、新しいメンバーとして参加する

### メンバーとグループの管理
- メンバーの退出・削除・名前の変更、グループ名の変更・削除を誰ができるかを、作成者がグループごとに選ぶ
  - **誰でも**（初期値）
  - **作成者のみ**：作成者がログインしているときだけ選べる（ログインなしでは、名前を入れれば誰でも作成者になれてしまうため）
- メンバーを削除してもグループから外れるだけで、アカウントの「行った」は消えない

## 非機能要件

- **端末**：スマホのブラウザを主に想定する（PCでも使える）
- **LINE**：招待URLは LINE のアプリ内ブラウザではなく、外部ブラウザで開かせる（Google ログインがアプリ内ブラウザで使えないため）
- **更新の反映**：他の人の変更は、画面を開いたときに反映されればよい（常時のリアルタイム同期は必須ではない）
- **費用**：無料枠の範囲で運用する
- **セキュリティ**：グループIDは推測できない文字列にし、グループの一覧は誰も取得できないようにする
- **個人情報**：扱うのは表示名、メールアドレス（ログイン時）、行った都道府県だけ

## やらないこと（MVP）

- 招待URLの再発行
- グループごとに内容が変わるリンクのプレビュー（OGP は全グループ共通）
- 市区町村単位、訪問日、写真
- 行き先の投票などの「決める」機能
- 匿名アカウントの自動削除
