# 要件定義

状態：レビュー待ち（2026-10-02：未決事項 Q-001〜Q-009 の決定と、`/review-docs` の指摘を反映）

## 目的

友達グループで「今まで行ったことのある都道府県」を日本地図に塗って共有し、全員まだ行っていない県を見つけて、次の旅行先を決めやすくする。

## 利用者

- 友達同士の小さなグループ（1グループ最大20人）
- スマホで使う。招待URLは主に LINE で送られる

## 機能要件

### グループ
- グループを作ると招待URLが発行される。URLを知っている人は誰でも参加・閲覧できる
- 招待URLの再発行はしない（MVP）
- 1グループの上限は20人

### 地図
- **わたし**：地図か一覧をタップして、自分の「行った」を付け外しする
- **みんな**：行った人が多い県ほど濃く塗る。県をタップすると誰が行ったか見られる
- **全員まだ行っていない県**を強調表示する
- **メンバー別**：選んだ人の行った県だけを表示する
- メンバーの色は、参加したときに自動で決まる（使われていない色から順に。足りなければ重複してよい）。色を変える操作はない（MVP）

### メンバーの名前
- 名前はグループごとに入力する。ログインしている人も同じ（アカウントには表示名を持たない）
- 1つのグループの中で名前は重複させない。ログインしている・いないに関係なく、全員に当てはまる
- 名前を変えられるのは、ログインしている本人だけ。ほかの人の名前は誰も変えられない
  - ログインせずに参加した人の名前は、誰も変えられない（本人を区別できないため）。打ち間違えたら、削除して入り直す（そのグループでの「行った」は消える）か、ログインしてから変える
  - 変えるときも、同じグループに同じ名前の人がいれば変えられない

### ログインなしで使う
- 会員登録なし。名前を入れるだけで参加できる
- **名前がそのまま本人**になる。同じ名前を入れれば、誰でもその人として操作・編集できる（信頼ベース）。ただし、ログインしたメンバーの名前には入れない（下の「ログインして使う」）
- 端末に前回の名前が残っていればそれを使う。残っていなくてもよい
- 端末に残っていた名前が、グループの今の状態と合わない（その人が削除された、ほかの人がログインしてその名前を自分のものにした、など）ときは、名前の入力からやり直す
- グループの切り替えはない。別のグループには別の招待URLから入る

### ログインして使う
- ログインの方法：メールアドレス＋パスワード、Google
- 参加しているグループを切り替えられる
- 「行った」はアカウントに保存され、参加している全グループに同期する。新しいグループに入っても入力し直さなくてよい
- ログインしたメンバーの「行った」と名前は、**本人しか編集できない**（信頼ベースの例外）。そのメンバーと同じ名前では、ほかの人は参加できない
- ログアウトすると、トップの画面に戻る。グループを開くと名前の入力から入る（ログインし直して入ることもできる）
- 退会できる。退会すると、アカウントと、参加していた各グループでのその人のメンバーが消える（各グループから退出したのと同じ）

| | ログインなし | ログインあり |
|---|---|---|
| 入り方 | グループごとの招待URL | 招待URL、またはグループ一覧 |
| 名前 | グループごとに入力する | グループごとに入力する |
| 名前の変更 | できない | 本人だけできる |
| グループの切り替え | なし | あり |
| 「行った」 | グループのメンバーごとに持つ | アカウントに保存し、全グループに同期する |
| 編集できる人 | そのグループの誰でも | 本人だけ |

### ログインなしで参加していた人がログインしたとき

グループでの「行った」（G）とアカウントの「行った」（U）を次のように扱う。

| 状況 | 挙動 |
|---|---|
| U が空（このアカウントでまだ「行った」を保存していない） | 確認なしで G をアカウントに引き継ぐ |
| G が U にすべて含まれている | 確認なしで U を表示する |
| それ以外 | 確認を出す |

> アカウントに保存されている「行った」（N県）をこのグループに反映しますか？
> - **アカウントのデータを使う**：このグループでの入力は破棄する
> - **合算する**：G と U を合わせてアカウントに保存する（参加中の他のグループにも反映される）

- この扱いになるのは、ログインしたときに開いていたグループだけ。同じ端末からログインなしで参加していた他のグループは、そのグループを開いて名前を入れたときに、下の「ログインした人がグループに入るとき」の流れになる（暫定。要確認：Q-005・Q-017）
- 開いていたグループに、自分のアカウントのメンバーがすでにいる（別の端末で参加済み）ときは、いま入っていたメンバーの「行った」を上の表と同じ流れでアカウントに合わせてから、そのメンバーを消す。1つのグループで、1人のアカウントにつながるメンバーは1人だけ

### ログインした人がグループに入るとき
- まだそのグループのメンバーでなければ、名前を入力してもらう
- 同じ名前のメンバー（ログインしていない人）がいれば「この人はあなたですか？」と聞く
  - **はい**：そのメンバーを自分のものにする（紐づけ）。データは上の表と同じ流れで扱う
  - **いいえ**：別の名前を入力してもらう（同じルールでもう一度確かめる）
- 同じ名前のメンバー（ログインしている人）がいれば、その名前では入れない
- 同じ名前がいなければ、新しいメンバーとして参加する

### メンバーとグループの管理
- メンバーの削除、グループ名の変更・削除を誰ができるかを、作成者がグループごとに選ぶ
  - **誰でも**（初期値）
  - **作成者のみ**：作成者がログインしているときだけ選べる（ログインなしでは、名前を入れれば誰でも作成者になれてしまうため）
- メンバーを削除してもグループから外れるだけで、アカウントの「行った」は消えない
- メンバーは自分で退出できる（管理できる人の設定に関係なく）。退出するとグループでの「行った」は消える
- 作成者のメンバーがいなくなったら（退出、削除、退会）、そのグループの作成者はいなくなり、管理できる人は「誰でも」に変わる。以後「作成者のみ」には誰も変えられない
- 最後の1人が退出すると、グループも削除する（退出の前に確認する）
- グループを削除しても、メンバーへの通知はしない
- 作成者は「作成者のメンバー」で決まる。ログインなしの作成者は、名前で入れば作成者として操作でき、ログインするとグループ設定ができる

### 分かっている限界（信頼ベースのため受け入れる）
- 「この人はあなたですか？」は自己申告で、本当に本人かは確かめていない。ログインしていない作成者のメンバーを、先に別の人が自分のものにすると、その人が作成者になる。ただし初期値の「誰でも」では、もともと誰でもメンバーやグループを削除できるので、増える被害は「作成者のみ」に変えてほかの人を締め出せることだけ。起きたらグループを作り直してもらう
- メンバーを削除しても、招待URLは変わらない（再発行しない）ので、その人はまた参加できる。削除は「追い出す」ためのものではない
- ログインしていないメンバーは、「作成者のみ」の設定でも、その名前で入れば誰でも退出させられる（本人を区別できないため。仕組みは基本設計で決める：要確認：Q-018）

## 非機能要件

- **端末**：スマホのブラウザを主に想定する（PCでも使える）
- **LINE**：招待URLは LINE のアプリ内ブラウザではなく、外部ブラウザで開かせる（Google ログインがアプリ内ブラウザで使えないため）
- **更新の反映**：他の人の変更は、画面を開いたときに反映されればよい（常時のリアルタイム同期は必須ではない）
- **費用**：無料枠の範囲で運用する
- **セキュリティ**：グループIDは推測できない文字列にし、グループの一覧は誰も取得できないようにする
- **個人情報**：扱うのはメンバーの名前、メールアドレス（ログイン時）、行った都道府県だけ。ログインしている人は、退会すればこれらを消せる

## やらないこと（MVP）

- 招待URLの再発行
- グループごとに内容が変わるリンクのプレビュー（OGP は全グループ共通）
- 市区町村単位、訪問日、写真
- 行き先の投票などの「決める」機能
- 匿名の利用者の記録の自動削除。使われなくなったグループも残り続ける（最後の1人が退出したときにグループを削除するのは、退出の操作の一部として行う）
- メンバーの色の変更
