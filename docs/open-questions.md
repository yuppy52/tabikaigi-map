# 未決事項

状態：下書き

まだ決まっていない論点を、ここで一本化して管理する。決めたら、決めた内容を該当ドキュメント（requirements、use-cases、design、ADR）に反映し、この表には反映先へのリンクだけを残す（[ルール](../.claude/rules/docs.md)）。

- ID（Q-001…）は振り直さない。不要になったら状態を「取り下げ」にして欠番にしない
- 他のドキュメントでは「（要確認：Q-001）」のように参照する
- 状態：**未決**（利用者と決める）／**要調査**（調べてから決める）／**決定**
- 「決める段階」：要件定義（REQ-ID を振る前）／基本設計／実装前
