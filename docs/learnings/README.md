# 学びの記録（learnings）

作業の中で分かったこと、ハマったこと、レビューで指摘されたことを1件1ファイルで残す場所。`/compound` で書く。

- ファイル名：`YYYY-MM-DD-<slug>.md`
- 先頭の `tags` と `area` で探せるようにする
- docs やコードを読めば分かることは書かない。「なぜそうなったか」「次にどうするか」を残す
- 今後ずっと守るべきことになったら、CLAUDE.md や `.claude/rules/` に反映する（反映したら、その旨を学びのファイルに書き足す）

設計やレビューの前に、関係する学びがないか `tags` で探す。
