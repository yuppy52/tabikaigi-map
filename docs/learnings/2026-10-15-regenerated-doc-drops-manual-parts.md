# 作り直す文書は、作り直すたびに手で書いた部分が消える

## 何が起きたか
要件IDの対応表（`docs/design/traceability.md`）は、設計書の本文から要件IDを集めるスクリプトで作り直している。2026-10-13 と 2026-10-15 に作り直したとき、どちらも、冒頭の状態の行（それまでの経緯）が消えた。2026-10-15 には、同じ変更の中で手で足した「要件に対応しない設計」の3行（目印のヘッダー、`/api/health`、Turnstile）も消えた。差分を見て気づき、足し直した。

## 原因
- スクリプトは、表の部分だけでなくファイル全体を書き直す。手で書く部分（状態の行、要件に対応しない設計）を残す作りになっていない
- 手で書く部分を足してからスクリプトを流すと、足した分が消える。順番を逆にしていた
- スクリプトは Claude のセッションの一時置き場（scratchpad）にあり、リポジトリにない。次のセッションでは使えず、作りも見直せない

## どうしたか
- 作り直した後に `git diff` を見て、状態の行と「要件に対応しない設計」を足し直した

## 次にどうするか
- 対応表を作り直すときは、スクリプトを先に流し、そのあとで状態の行と「要件に対応しない設計」を手で直す。最後に `git diff` で、消えた行がないかを見る
- スクリプトをリポジトリ（`tools/`）に置き、手で書く部分を残す作りにする（別の作業として行う）
