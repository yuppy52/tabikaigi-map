# 借りたデータの条件は、配布元の README だけでなく、元のデータを出しているところの公式の条件まで見る

## 何が起きたか
都道府県の形は、モックのときから dataofjapan/land（GitHub）の `japan.topojson` を使っていた。LICENSE を決める（2026-10-16）まで、条件を一度も調べていなかった。調べると、配布元には LICENSE がなく、README に「営利なら地球地図日本に利用の報告」とあった。ところが、元のデータを出している国土地理院のいまのページには、報告の決まりは見当たらず、「商用・非商用に関わらず出典を書く」とだけあった。配布元の README は古いと考えられるが、どちらに従えばよいかを、公式の文書1つで言い切れなかった。

## 原因
- モックを作るときに、動く見た目を優先して、借りるデータの条件を見なかった。リポジトリを公開した後も、そのままだった
- 配布元は、元のデータを変換して置いているだけで、条件を正しく引き継いでいるか（いまも同じか）は分からない

## どうしたか
- 元のデータを出しているところ（国土交通省）が「商用利用も可能」と公式に書いている国土数値情報 N03 に替えた（ADR 0007）
- 出典と条件を NOTICE.md に書き、MIT の対象外と書き分けた。画面にも出典を出す決まりにした

## 次にどうするか
- 外から借りるデータ（地図、画像、フォント、文言の一覧など）は、入れるときに条件を見る。後回しにしたら、遅くとも LICENSE を決めるときと、公開の前に見る
- 配布元（GitHub などで変換して置いている人）の README だけで判断せず、元のデータを出しているところの公式の条件を確かめる。食い違ったら、元のデータを直接使えないかを考える
- 条件は「商用でもよいか」「出典の書き方」「報告や申請が要るか」「加工・再配布してよいか」の4つで比べる
